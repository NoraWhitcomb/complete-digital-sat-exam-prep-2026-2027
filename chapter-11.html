Question 709

Question 710

Answer: B

Question 711

Question 712

Question 713

Question 717

Answer: B

The correct answer is B (12.5): with six values, the median is the mean of the middle two, 10 and 15, which is 12.5. The values 10 and 15 are the middle numbers on their own. The value 14.5 is the mean of all six distances. With an even number of values, average the middle two.

Question 718

Answer: A

The correct answer is A (The mean increases, and the median stays the same): it correctly reads what the model or data show. The large new value pulls the mean up, but the middle value, 27, does not change. The median is the middle value, so it stays the same. Only the mean changes, so the last two choices are wrong.

Question 719

Answer: B

The correct answer is B (Set Y has a larger standard deviation than set X): it correctly reads what the model or data show. Set Y's values spread from 60 to 84, while set X's stay between 70 and 74, so set Y is more spread out. Set X is bunched closely around 72, so it has the smaller spread. Both sets have a mean of 72, and set Y has the larger range.

Question 722

Answer: A

Question 723

Answer: C

The correct answer is C (-4): the next sentence explains why it is right. The predicted speed is 2.3(10) + 41 = 64, and the residual is actual minus predicted, 60 - 64 = -4. The value 4 subtracts in the wrong order. The values 64 and 60 are the predicted and actual speeds.

Question 724

Answer: D

Question 725

Answer: A

The correct answer is A (A negative association): as temperature rises, hot drink sales fall, which is a negative association. Positive associations would mean both rise together. There is a clear pattern, so there is an association, and nothing suggests an exponential curve. Falling from left to right means negative.

Question 726

Answer: C

The correct answer is C (The age of 40 is far outside the range of the data used): it reads the model correctly. The data cover only ages 10 to 16, so predicting age 40 goes far beyond the data. Lines of best fit never pass through every point, which is not the problem here. These lines can make predictions within the data, and a positive slope is not a reason they fail.

Question 727
