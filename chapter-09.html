Question 571

Answer: A

The correct answer is A (Exponential): each output is double the one before, 5, 10, 20, 40, so the outputs share a constant ratio of 2. The differences are 5, 10, and 20, which are not equal, so the function is not linear. The differences do not change by a steady amount either, so the function is not quadratic, and nothing suggests absolute value. Check differences first, then ratios, to identify a function type.

Question 572

Answer: C

The correct answer is C (Quadratic): the outputs 2, 5, 10, 17 have differences of 3, 5, and 7, which grow by 2 each time. The differences are not equal, so the function is not linear. The ratios between outputs are not constant, so it is not exponential, and absolute value does not fit. When the differences change by a steady amount, the pattern is quadratic.

Question 573

Answer: A

The correct answer is A (Linear): the outputs rise by 4 each time x rises by 1, which is a constant difference. Quadratic functions have differences that change, but these stay at 4. Exponential functions multiply by a constant ratio, and 11 divided by 7 is not the same as 15 divided by 11. Equal differences mean a linear function.

Question 574

Answer: D

The correct answer is D (f(x) = 300(0.9)ˣ): the next sentence explains why it is right. Multiplying by 0.9 each time x rises by 1 means the output drops by 10% each step. Subtracting 0.9x lowers the output by the same amount each time, not the same percent. The other two functions are a quadratic and a linear function with a positive slope.

Question 575

Answer: A

The correct answer is A (4): the highest exponent in the polynomial is 4, so its degree is 4. The value 5 is the leading coefficient, not the degree. The value 3 is a lower exponent, and 8 is the constant term. Degree means the greatest exponent on x.

Question 576

Answer: C

The correct answer is C (f(x) = 6 · 3ˣ): the next sentence explains why it is right. An initial value of 6 that triples each step gives 6 times 3 raised to the power x. Swapping 3 and 6 makes the starting value 3 and the factor 6. 6x³ is a cubic polynomial, and 6 + 3x is linear.

Question 577

Answer: B

The correct answer is B (Opens downward, with a maximum value): the next sentence explains why it is right. The number in front of x² is -4, which is negative, so the parabola opens downward and its vertex is a maximum. Parabolas that open upward need a positive number in front of x². Downward parabolas have a highest point, not a lowest point, so they have a maximum.

Question 578

Answer: D

The correct answer is D (x = -2): the next sentence explains why it is right. The axis of symmetry is x = -12/(2 times 3), which is x = -12/6 = -2. Choosing x = 2 forgets the negative sign in the formula. Choosing x = -4 divides by 3 instead of by 6, and x = -7 uses the constant term.

Question 579

Answer: C

The correct answer is C ((5, -4)): the next sentence explains why it is right. The vertex x-value is 10/2 = 5, and f(5) = 25 - 50 + 21 = -4. (-5, 96) uses the wrong sign for the x-value. (5, 4) has the wrong sign for the y-value, and (-4, 5) swaps the coordinates.

Question 580

Answer: B

The correct answer is B ((0, 11)): the y-intercept occurs when x is 0, and g(0) = 11. (0, 5) uses the coefficient of x² instead of the constant. (11, 0) is on the x-axis, and (0, -3) uses the coefficient of x. In standard form, the constant term is the y-intercept.

Question 581

Answer: D

The correct answer is D (0): the next sentence explains why it is right. The parabola opens upward and its lowest point is at a height of 7, so it never reaches the x-axis. One x-intercept would need the vertex to sit on the x-axis. Two intercepts would need the vertex below the x-axis, and a parabola cannot cross the axis three times.

Question 582

Answer: D

The correct answer is D (3): here is why. The vertex lies halfway between the x-intercepts, so its x-value is (-3 + 9)/2 = 3. The value 6 is the sum of the intercepts, not their average. The values -6 and 12 come from subtracting the intercepts or other slips.

Question 583

Answer: A

The correct answer is A (x = 2): the next sentence explains why it is right. Equal outputs at x = -2 and x = 6 are mirror images, so the axis is halfway between them, at x = 2. Choosing x = 4 is half the distance between the points, not their midpoint. Choosing x = 8 is the distance between them, and x = 15 is the output.

Question 584

Answer: B

The correct answer is B (47): the next sentence explains why it is right. The vertex is at t = 30/10 = 3, and h(3) = -45 + 90 + 2 = 47 metres. The value 3 is the time of the greatest height, not the height itself. The values 30 and 137 come from using a coefficient or a sign error.

Question 585

Answer: D

The correct answer is D (x = -4 and x = 7): the next sentence explains why it is right. Each factor equals zero at one input, so x + 4 = 0 gives -4 and x - 7 = 0 gives 7. Choosing x = 4 and x = -7 flips both signs. Multiplying by 2 does not change the intercepts, and 2 is a coefficient, not a zero.

Question 586

Answer: B

The correct answer is B ((-1, 8)): the next sentence explains why it is right. In vertex form, (x + 1) means h = -1, and the + 8 gives k = 8, so the vertex is (-1, 8). (1, 8) misreads the sign inside the brackets. (-1, -8) changes the sign of k, and (-3, 8) uses the coefficient instead of h.

Question 587

Answer: A

The correct answer is A ((x + 3)² - 4): the next sentence explains why it is right. Vertex form shows the minimum directly, and (x + 3)² - 4 expands back to x² + 6x + 5. (x + 1)(x + 5) is factored form, which shows the zeros, not the minimum. Choosing x(x + 6) + 5 or x² + 6x + 5 does not show the minimum as a single constant.

Question 588

Answer: C

The correct answer is C ((x - 6)(x + 2)): the next sentence explains why it is right. Here, (x - 6)(x + 2) expands to x² - 4x - 12, with zeros 6 and -2. (x - 2)² - 16 is vertex form, which shows the minimum. Choosing x(x - 4) - 12 or x² - 4x - 12 does not show the zeros directly.

Question 589

Answer: A

The correct answer is A (2x² - 12x + 13): the next sentence explains why it is right. Expand (x - 3)² to x² - 6x + 9, double it, then subtract 5. Ending with + 4 forgets to multiply the 9 by 2. Using -6x forgets to multiply that term by 2, and + 12x has the wrong sign.

Question 590

Answer: B

The correct answer is B (x² + 2x - 15): the next sentence explains why it is right. Multiplying gives x² - 3x + 5x - 15, which simplifies to x² + 2x - 15. Choosing x² - 2x - 15 gets the middle term's sign wrong. Ending with + 15 multiplies 5 by 3 instead of -3, and x² - 15 forgets the middle term.

Question 591

Answer: D

The correct answer is D (y = -6x²): the next sentence explains why it is right. The larger the size of the number in front of x², the narrower the parabola, and 6 is the largest size here. 0.5 and -0.2 have small sizes, so those parabolas are wide. 3 is larger than those but smaller than 6.

Question 592

Answer: A

The correct answer is A (a < 0, and the vertex has an x-coordinate of 5): it reads the model correctly. Here, a maximum means the parabola opens downward, so a is negative, and the vertex lies halfway between 2 and 8, at 5. Any positive value of a would make the parabola open upward, with a minimum. The values 10 and 6 are not halfway between the zeros.

Question 593

Answer: B

The correct answer is B (-6, 1, and 4): the next sentence explains why it is right. Each factor gives one zero: x + 6 gives -6, x - 1 gives 1, and x - 4 gives 4. 6, -1, and -4 flip every sign. The other choices leave out one of the three zeros.

Question 594

Answer: C

The correct answer is C (p(x) = x(x + 2)(x - 5)): the next sentence explains why it is right. The zeros -2, 0, and 5 come from the factors x + 2, x, and x - 5. Choosing x - 2 and x + 5 gives zeros of 2 and -5, which have the wrong signs. Leaving out the factor x removes the zero at 0, and the last choice has a zero at 2.

Question 595

Answer: A

The correct answer is A (x - 3): p(3) = 0 means 3 is a zero, so x - 3 must be a factor. Choosing x + 3 would give a zero at -3. 3x gives a zero at 0, and x - 1/3 gives a zero at 1/3. When an output is zero at some input r, x - r is a factor.

Question 596

Answer: A

The correct answer is A (x + 4 is not a factor): the next sentence explains why it is right. Here, p(-4) = 9, not 0, so -4 is not a zero and x + 4 is not a factor. Saying x + 4 is a factor would need p(-4) to equal 0. Nothing is known about p(4), and -4 is not a zero since p(-4) is 9.

Question 597

Answer: D

The correct answer is D (It touches the x-axis and turns back): the next sentence explains why it is right. The factor x + 1 is squared, so the zero at -1 repeats and the graph bounces off the axis. Crossing the x-axis happens at zeros that appear an odd number of times. The point at x = -1 lies on the x-axis, and the graph touches it there.

Question 598

Answer: C

The correct answer is C (Both ends point up): the next sentence explains why it is right. The degree is 4, which is even, and the leading coefficient 3 is positive, so both ends point up. Both ends point down only when the leading coefficient is negative. Ends that point in opposite directions belong to odd-degree polynomials.

Question 599

Answer: C

The correct answer is C (Left end up, right end down): the next sentence explains why it is right. The degree is 5, which is odd, and the leading coefficient is negative, so the left end points up and the right end points down. The left end down and right end up pattern belongs to a positive leading coefficient. Both ends pointing the same way happens only with even degrees.

Question 600

Answer: B

The correct answer is B (2): here is why. The zeros are 2 and -3, and the factor x - 2 appears twice but gives only one distinct intercept. The value 3 counts x = 2 twice. The values 1 and 4 miscount the distinct zeros.

Question 601

Answer: C

The correct answer is C (It increases by 12% each hour): the next sentence explains why it is right. The base 1.12 means the count is multiplied by 1.12 each hour, which is a 12% increase. 1.12% confuses the base with the percent. 112% describes the new total, not the increase, and the change is a percent, not a fixed number of bacteria.

Question 602

Answer: D

The correct answer is D (It decreases by 18% each year): the next sentence explains why it is right. The base 0.82 means the value keeps 82% each year, which is an 18% decrease. An 82% decrease confuses the part kept with the part lost. 0.82% misreads the base as a percent, and the value falls rather than rises.

Question 603

Answer: B

The correct answer is B (P(t) = 6,400(0.75)ᵗ): here is why. Here, a 25% decrease means 75% remains each year, so the base is 0.75. Using 0.25 keeps only 25% each year, which is a 75% decrease. Using 1.25 would be growth, and subtracting 0.25t is linear.

Question 604

Answer: B

The correct answer is B ((0, 7)): at x = 0, 4 to the power 0 is 1, so the output is 7. (0, 4) uses the base instead of the starting value. (0, 28) multiplies 7 by 4, and exponential graphs of this form never pass through (0, 0). Any base raised to the power 0 equals 1.

Question 605

Answer: A

The correct answer is A (2): the next sentence explains why it is right. 3 times 0.5 to the power x shrinks toward 0 as x grows, so the whole function approaches 0 + 2 = 2. 0 is the asymptote before the + 2 shift. 3 is the starting coefficient, and 5 is the value at x = 0.

Question 606

Answer: D

The correct answer is D (220.5): 200 times 1.05 squared is 200 times 1.1025, which is 220.5. 210 adds 5% only once. 420 doubles the amount, and 205 adds $5 instead of 5%. Exponential growth multiplies by the factor once for each step.

Question 607

Answer: C

The correct answer is C (x ≥ 4): the next sentence explains why it is right. The expression under the root must be at least 0, so 2x - 8 ≥ 0 and x ≥ 4. Choosing x ≥ 8 forgets to divide by 2. Choosing x ≤ 4 reverses the sign, and x ≥ -4 has the wrong sign.

Question 608

Answer: B

The correct answer is B (x = -6): the denominator x + 6 equals 0 when x = -6, so g is undefined there. Choosing x = 6 has the wrong sign. Choosing x = -1 makes the numerator 0, which is allowed, and x = 1 has no special meaning here. Only the denominator can make a fraction undefined.

Question 609

Answer: A

The correct answer is A (x = 2 and x = 3): the next sentence explains why it is right. The denominator factors as (x - 2)(x - 3), which equals 0 at x = 2 and x = 3. Negative 2 and negative 3 flip the signs of the zeros. 6 and the pair 1 and 6 come from the constant term, not the factors.

Question 610

Answer: C

The correct answer is C (x = -7): the denominator is 0 at x = -7, so the graph has a vertical asymptote there. Choosing x = 7 has the wrong sign. Choosing x = 2 uses the numerator, and y = 2 is a horizontal line. Vertical asymptotes are written as x equals a number.

Question 611

Answer: C

The correct answer is C ((-5, 0)): the next sentence explains why it is right. The graph starts where x + 5 = 0, at x = -5, and the output there is 0. (5, 0) has the wrong sign. (0, 5) and (0, -5) are on the y-axis, but the graph starts on the x-axis.

Question 612

Answer: D

The correct answer is D (y = 0): the next sentence explains why it is right. As x grows very large, 6 divided by a huge number approaches 0, so the horizontal asymptote is y = 0. Choosing y = 6 uses the numerator as if it were the limit. Choosing y = 1 or y = -1 relates to the vertical asymptote at x = 1, not the horizontal one.

Question 613

Answer: B

The correct answer is B (g(x) = f(x) - 5): subtracting 5 outside the function lowers every output by 5. Subtracting or adding inside the brackets shifts the graph left or right. Adding 5 outside moves the graph up, not down. Changes outside the function move it up or down.

Question 614

Answer: A

The correct answer is A (Shifted 3 units to the left): adding 3 inside the function shifts the graph 3 units left. Shifting to the right would need x - 3 inside the brackets. Up and down shifts come from adding outside the function. Inside changes move the graph the opposite way from the sign.

Question 615

Answer: A

The correct answer is A (10): g(6) = f(6 - 2) + 1 = f(4) + 1 = 9 + 1 = 10. 8 subtracts 1 instead of adding it. 11 and 7 come from other errors with the input or the shift. Work out the input inside the brackets first.

Question 616

Question 617

Moving right would need x - 6 inside the brackets. Moving up would need + 2, and the last choice swaps the two numbers.

Question 618

Question 631
